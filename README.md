# Каталог учебных аудиторий

## Что умеет программа

- Создавать аудитории
- Добавлять, искать и удалять аудитории по номеру
- Искать аудитории по типу и по названию
- Показывать все аудитории в отсортированном порядке
- Сохранять данные в JSON-файл и загружать их обратно
- Защищать данные: если JSON-файл сломан, каталог в памяти не испортится

## Как запустить

Проверить, как всё работает:
`python -m catalog`

Запустить тесты:
`python -m pytest`

Проверить код на ошибки стиля:
`python -m ruff check .`
